## 🚀 Overview

**TIA IDE Studio & Enterprise Portal** is a full-stack local Integrated Development Environment (IDE) and Enterprise Operations Platform built with **Node.js**, **Express 5**, and **WebSockets**.

### Key Modules
1. **TIA IDE Studio Workbench**:
   - Multi-tab Code Editor with line gutter, coordinate tracking, and code formatter (`Shift+Alt+F`).
   - Workspace File Explorer (`workspace/`) with file/folder creation, deletion, and instant switching.
   - Live Split Web Preview (`http://localhost:3000/workspace/index.html`).
   - Integrated PowerShell / CMD Terminal Console.
   - Universal Code Runner (`F5`) for JavaScript and Python (with built-in Mechatronics & CAD Simulation Engine).
   - Software Forge 1-Click Project Generator & AI Code Diagnoser.
2. **Executive Login & Live Attendance**:
   - Role-based authentication (`CEO`, `CMO`, `Project Manager`, `Technical Manager`, `P.A`) via Username / Email / Mobile + Password (`tia123`).
   - 1-Click Check In / Check Out with real-time shift stopwatch and online presence indicators.
3. **Executive Connect & Messaging**:
   - Real-time WebSocket channels, file sharing (up to 2GB), WhatsApp direct links, voice notes (`MediaRecorder`), Speech-to-Text dictation, and Text-to-Speech readout.
4. **Courses & Dealers/Clients Hub**:
   - Short-term technical courses catalog & creator.
   - Comprehensive Customers/Clients, Software Contracts, and Dealers/Channel Partners reference hub.
5. **Students & Invoicing / Receipts**:
   - Student enrollment, fee tracking, auto-shift to Completed archive, and printable GST Bill-Receipts (`37EYLPM8018M1ZN`).
6. **Employees Payslip Management**:
   - Salary + Extra Commission calculation and printable official executive payslips.

## 🛠️ Quick Start (Run Locally)

```bash
# Install dependencies
npm install

# Start TIA IDE Studio & Enterprise Portal
npm start
```

Or double-click **`launch-ide.bat`** on Windows to launch the server and open the IDE in application window mode at [http://localhost:3000](http://localhost:3000).
